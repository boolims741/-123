# EastAsiaMap v9 candidate

[Download EastAsiaMap_v9.zip](EastAsiaMap_v9.zip?raw=true)

사용자가 제공한 v8 기반 수정 후보입니다. 실제 게임의 캠페인 로딩 성공은 아직 검증되지 않았습니다. NavalDLC가 필요합니다.

정착지 XML 등록을 복구하고, 외곽 지형 높이 이상값과 42개 타일의 높이 경계를 보정했습니다. 지형과 내비메시 바이너리는 원본입니다. 기존 시험본을 Modules 밖으로 보관한 뒤 ZIP의 EastAsiaMap_Trial 폴더를 Modules에 넣고 새 샌드박스로 확인합니다.
